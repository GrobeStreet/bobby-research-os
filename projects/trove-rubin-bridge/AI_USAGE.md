# AI usage and verification

This repository was developed with substantial AI assistance for source discovery, architecture critique, code scaffolding, test generation and documentation drafting.

AI output is **not** treated as an authority.

## Verification boundary

Consequential claims in the repository are limited to behavior demonstrated by deterministic tests in this repository or facts recorded in `evidence/SOURCES.md` and traced to primary/public project documentation or source code.

The current fixture is synthetic and explicitly labeled as such.

## What AI did not establish

AI did not validate the production ANTARES LSST schema, the TROVE team's preferred broker/topic, live streaming credentials, production database semantics, or scientific performance.

Those claims remain open until direct evidence is available.

## Working rule

**AI proposes. Deterministic systems verify. Evidence remains traceable.**
